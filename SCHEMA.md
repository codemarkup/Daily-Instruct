## Tables

## Row Level Security (RLS) Policies

1. **Enable RLS on `articles` table**.
2. **Select Policy (Public)**: 
   - Allow `SELECT` for all users (`true`).
3. **Insert/Update/Delete Policy (Authenticated/Service Role)**:
   - Allow all operations for `authenticated` users or `service_role`.

## Supabase SQL Setup Script
```sql
CREATE TABLE articles (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  slug TEXT UNIQUE NOT NULL,
  title TEXT NOT NULL,
  description TEXT NOT NULL,
  author TEXT NOT NULL,
  date TIMESTAMP WITH TIME ZONE NOT NULL,
  "readTime" TEXT NOT NULL,
  image TEXT NOT NULL,
  category TEXT NOT NULL,
  specific TEXT,
  trending BOOLEAN DEFAULT FALSE,
  featured BOOLEAN DEFAULT FALSE,
  "topStory" BOOLEAN DEFAULT FALSE,
  grid BOOLEAN DEFAULT FALSE,
  "homeFeatured" BOOLEAN DEFAULT FALSE,
  "homeLatest" BOOLEAN DEFAULT FALSE,
  "homeTrending" BOOLEAN DEFAULT FALSE,
  "homeTopStory" BOOLEAN DEFAULT FALSE,
  content JSONB NOT NULL DEFAULT '[]'::jsonb,
  keywords TEXT,
  "metaDescription" TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Enable RLS
ALTER TABLE articles ENABLE ROW LEVEL SECURITY;

-- Allow public read access
CREATE POLICY "Allow public read access" ON articles
  FOR SELECT USING (true);

-- Allow authenticated users full access (admin panel)
CREATE POLICY "Allow full access for authenticated users" ON articles
  FOR ALL TO authenticated USING (true) WITH CHECK (true);
```
